ConvergencePlots.AbstractPlotBackend — Type
AbstractPlotBackend

Abstract supertype of the plotting backends supported by ConvergencePlots. Each backend is provided by a package extension that is automatically loaded when the corresponding plotting package is loaded:

  • ConvergencePlotsPythonPlotExt for PythonPlot (the default backend),
  • ConvergencePlotsPlotsExt for Plots,
  • ConvergencePlotsMakieExt for Makie.

Use pyplotbackend, plotsbackend, makiebackend or default_backend to get a backend instance.

ConvergencePlots.ConvergencePlot — Type
ConvergencePlot(
    npoints::Int = 100000;
    backend = default_backend(),
    names = ["Residual"],
    options = nothing,
    show = false,
    figsize = (20, 10),
)

Create an empty convergence plot that keeps the last npoints history points for every metric in names. Older points are overwritten. A plotting package must be loaded for the default backend to be available, see default_backend.

Keyword arguments

  • backend: the plotting backend, e.g. pyplotbackend, plotsbackend or makiebackend. The default is default_backend.
  • names: a Vector{String} of the convergence metrics to plot. The default value is ["Residual"].
  • options: a dictionary mapping each name in names to a NamedTuple of plotting options to pass to the backend, e.g. (label = "KKT residual", ls = "--", marker = "+") for the PythonPlot backend. If label is not passed, it defaults to the corresponding name in names. A single NamedTuple of options without the label option can also be passed, and it will be used for all the names.
  • show: if true the empty figure will be displayed. This is false by default.
  • figsize: the (width, height) of the figure. The unit is backend dependent: inches for PythonPlot; for Plots and Makie the value is scaled by a factor of 100 and interpreted as pixels.
ConvergencePlots.ConvergencePlot — Type
ConvergencePlot{B}

A live convergence plot that keeps track of the history of one or more convergence metrics. Points are added with addpoint! or addpoints!, and the plot is (re)drawn with updateplot!. The plotting is delegated to a backend of type B <: AbstractPlotBackend provided by a package extension; see AbstractPlotBackend.

ConvergencePlots.addpoint! — Method
addpoint!(plot::ConvergencePlot, y::Real; kwargs...)
addpoint!(plot::ConvergencePlot, y::Dict; update = true, kwargs...)

Add a single point to the history of plot and update the plot.

The second argument can be a single value, in which case plot must have exactly one name, or a dictionary containing one value for each name in plot.names. Adding a point displays the plot by default; set the show keyword argument to false to stop the plot from being displayed. If update is false, the history is updated without redrawing the plot. All other keyword arguments are forwarded to updateplot!.

ConvergencePlots.addpoints! — Method
addpoints!(plot::ConvergencePlot, y::Dict; update = false, kwargs...)

Add a batch of points to the history of plot. The dictionary y maps each name in plot.names to a vector of points. If a batch is longer than plot.npoints, only the last plot.npoints points are kept. By default the plot is not updated after inserting the points; set update to true to redraw it, in which case all other keyword arguments are forwarded to updateplot!.

ConvergencePlots.closeplot! — Method
closeplot!(plot::ConvergencePlot)

Close the figure of plot and replace it with a new empty one.

ConvergencePlots.default_backend — Method
default_backend()

Return the default plotting backend: the PythonPlot backend if PythonPlot is loaded, otherwise the Plots backend if Plots is loaded, otherwise the Makie backend if Makie is loaded. An ArgumentError is thrown if none of these plotting packages is loaded.

ConvergencePlots.makiebackend — Function
makiebackend()

Return the Makie plotting backend. Makie must be loaded first, e.g. with using Makie (together with a backend such as CairoMakie or GLMakie). See also pyplotbackend and plotsbackend.

ConvergencePlots.plotsbackend — Function
plotsbackend()

Return the Plots plotting backend. Plots must be loaded first, e.g. with using Plots. See also pyplotbackend and makiebackend.

ConvergencePlots.pyplotbackend — Method
pyplotbackend()
plotsbackend()
makiebackend()

Return the plotting backend of the corresponding package. The package must be loaded first, e.g. with using PythonPlot, using Plots, or using Makie.

ConvergencePlots.updateplot! — Method
updateplot!(plot::ConvergencePlot; show = true, filename = nothing)

Redraw the plot with the current history of plot. If show is true, the figure is displayed. If filename is not nothing, the figure is saved to that file.
